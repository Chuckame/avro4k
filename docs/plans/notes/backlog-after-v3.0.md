# Backlog — improvements and features set aside for after v3.0

**What this is:** the list of improvements the user set aside, to implement or merge themselves later (v3.0.x or
v3.1). v3.0's goal is multiplatform support and the breaking changes it allows; an improvement that changes no
structure or public contract can come in a patch release. Maintained by the orchestrator: add an item when one is set
aside, mark it when the user takes it. Each item says where its design and numbers are.

| # | Item | Why set aside | Design and numbers |
|---|---|---|---|
| 1 | **Reordering encoder without closures** — the encoder used when a class's properties come in another order than the writer schema's fields: buffer values in arrays owned by the encoder, replay in writer order at `endStructure`. Per reordered record, 4 + 2n objects → 0 | User, 2026-10-20: later, no structural change; no end-to-end workload reorders fields (only `FieldOrderMicroBenchmark.write`) | `m5-decomposition.md`, M5-10. Builds on encoder reuse per nesting level (M5-05): reuses its slot |
