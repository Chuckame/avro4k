# Backlog — improvements and features set aside for after v3.0

**What this is:** the list of improvements the user set aside, to implement or merge themselves later (v3.0.x or
v3.1). v3.0's goal is multiplatform support and the breaking changes it allows; an improvement that changes no
structure or public contract can come in a patch release. Maintained by the orchestrator: add an item when one is set
aside, mark it when the user takes it. Each item says where its design and numbers are.
