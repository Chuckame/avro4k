## 3. Deviations from the m3-13 spec

1. **Non-JVM `AnySerializer.encodingCache`**: a **strong** copy-on-write `Map<KClass<out Any>, SerializationStrategy<Any>>`
   in a stdlib `kotlin.concurrent.atomics.AtomicReference` (lock-free: load, miss → infer → CAS loop inserting into a
   copy; a lost race costs one extra inference), instead of m3-13 §6's `WeakKeyCache` — the user's decision (m3-13 open
   point 2). KDoc gives the reasons (classes never unloaded off the JVM; a weak cache would churn if `::class` yields a
   fresh object; `KClass` equality still matches). Added `internal val encodingCacheSize` for the test.
2. The KDoc of the non-JVM `AnySerializer` documents that a generic serializable class that is neither a `Collection`
   nor a `Map` (e.g. `Pair`) is not inferred without reflection (m3-13 open point 3); appended to
   `b8-migration-items.md` ("Platform differences").
3. None other: file list, declarations and build change are the spec's.
