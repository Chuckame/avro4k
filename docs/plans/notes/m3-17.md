**Findings from the run:**
- **Apache 1.12.1 → 1.12.2 changes Apache's own speed by −32% to +18%** on some rows (`simple` read @1 −32%,
  `complex` read @1 +18%, `lists` read @100 −11%). Confirmed by a dedicated check: M0's tree with only Apache bumped to
  1.12.2 (and head's class-trust setup) reproduces head's Apache numbers on all three rows. So Apache is not a same-code
  noise reference between M0 and head any more; verdicts rest on separation across invocations, and every ratio to
  Apache names its version. Head also moved Kotlin 2.3.21 → 2.4.20, Jackson 2.21.3 → 2.22.3, kotlinx-io 0.8.2 → 0.9.1
  (merges from `main`); kotlinx-serialization 1.11.0 and JMH 1.37 are the same on both sides.
- **The machine idle-slept mid-run** in the first attempt: `caffeinate -i` was held per Gradle invocation only, and the
  script's power poll (every 15 s) left a gap after each invocation. With the display already off, macOS slept at 03:00
  and stayed in sleep / dark wake until the end (one `complex-read` took 25 min instead of 6; another full sleep during
  the micro run). Everything measured after 03:00 was discarded (median unmoved, single rows ±30%) and measured again
  under one `caffeinate -dimsu -w $$` over the whole script, with `pmset -g log` checked for `Sleep`/`DarkWake` after
  each invocation. `:benchmark:checkBenchmarkPower` checks power, not sleep; a long unattended run needs both.
